# SoundGeo 0.3.0-alpha.2

The Windows download is now a single executable. Download
`soundgeo-0.3.0-alpha.2-windows-x64.exe` and run it on 64-bit Windows 10 or 11.
It includes FFmpeg, FFprobe, Tesseract with English language data, software OpenGL,
and the required runtimes. No separate tool installation or administrator
permission is needed. Startup unpacks verified files into a private temporary
folder and removes them after normal exit. Leave at least 1 GB free for startup.

The same EXE accepts CLI commands. `--portable-extract DIRECTORY` extracts the
complete package into a new folder for console scripts or custom tool overrides.
Explicit tool paths still take precedence over bundled defaults.

The download remains unsigned and experimental. Flight, terrain and GeoNames
reference data are prepared through the app as needed. The Linux download is
still an archive and uses distribution-provided runtime packages. See
[installation instructions](https://github.com/Donovoi/soundgeo/blob/v0.3.0-alpha.2/docs/installation.md).

Release qualification runs in Windows and Linux VMs. It covers Rust checks,
publication guards, package integrity, synthetic geolocation, silent audio intake,
and a visible desktop window. Windows additionally checks the single EXE with
external tools removed from PATH, DLL dependencies, video frame extraction and
English OCR, concurrent launches, cleanup, and corrupt-download rejection.
The validation JSON files contain the results for the exact downloads.

This release changes packaging and tool discovery. It does not establish broader
real-world accuracy within 1 km. Existing benchmark outcomes and unsupported
cases remain documented in the
[limitations](https://github.com/Donovoi/soundgeo/blob/v0.3.0-alpha.2/docs/limitations.md).

The Windows package includes FFmpeg under LGPL 2.1 or later, used as separate
executables. Its corresponding patched sources, dependency sources and build
scripts are in `soundgeo-0.3.0-alpha.2-windows-runtime-sources.zip`, provided with
this release. Embedded notices cover FFmpeg, Tesseract, Mesa and their dependencies.
