# SoundGeo 0.4.0-alpha.3

Every desktop action button now has a tooltip explaining its purpose and next
step. Help covers recording and URL intake, flight-data preparation, terrain,
aircraft filters, analysis, cancellation, speech, video clues and report exports.

Tooltips remain available on disabled controls. Checkboxes, dropdowns and their
choices, result tabs, candidate selection, links and expandable headings also
have explanations. File choosers explain which input they need.

URL downloads now show progress and a cancel button beside the URL controls.
Completion stays visible with the selected clip title, size, duration and an
**Analyze downloaded recording** button. Errors also appear there. Downloading
selects the recording; analysis starts when requested.

See the [desktop instructions](../../README.md#use-the-desktop-application).
The analysis methods, location acceptance rules and bundled tools are unchanged.
