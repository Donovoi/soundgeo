# SoundGeo 0.4.0-alpha.2

Video clues now have a **Read video clues during analysis** checkbox. Select a
video, tick the option, and choose **Analyze recording** to read visible place
names and clocks as part of the location-analysis workflow.

Missing GeoNames data is prepared automatically with progress messages and reused
from a verified local cache. Choose a two-letter country code for a smaller
download, or ALL for worldwide data. Audio-only recordings skip place-data
preparation. Offline mode reuses prepared data.

Every video-clue action has a tooltip. Manual GeoNames and Tesseract paths are
under **Advanced video settings**; the Windows EXE uses its bundled OCR tools by
default. **Read video clues only** remains available without flight data.

A video-clue failure is shown alongside the results and location analysis
continues. Cancelling stops the remaining stages. Completed clues remain
available if the flight-data setup needs attention.

Video text remains separate evidence: named places do not establish the camera
position, and visible clocks are not applied to the flight search automatically.
Video OCR currently uses English. See the [instructions](../../README.md#optional-video-clues)
and [limitations](../limitations.md#video-text-clues).

This is an unsigned experimental release. The existing speech, translation,
URL-download and aircraft-analysis features are retained.
