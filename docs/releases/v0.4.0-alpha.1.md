# SoundGeo 0.4.0-alpha.1

This experimental release adds optional local speech transcription and English
translation for English, Mandarin Chinese, Hindi, Spanish, Arabic, French,
Bengali, Portuguese, Indonesian and Urdu.

Tick **Transcribe speech and translate to English** after selecting a recording.
SoundGeo detects speech and language, then downloads the required verified model
files with progress messages. Hindi and Urdu require a script choice. English
recordings skip the translator. A compact translation option uses less disk and
memory than the default quality model.

The Windows EXE includes native speech runtimes, small detectors and fonts.
Large recognition and translation weights remain outside the EXE and are reused
from a local cache. No account, API key or separately installed AI runtime is
needed. Original transcripts and translations can be exported as JSON, TXT,
SRT and VTT. Completed original text survives a translation failure or desktop
cancellation. Speech results remain independent of geolocation acceptance.

Use **Analyze speech only** without flight data, or the `transcribe` command.
Open saved speech reports with `view-speech`. See [speech instructions](../speech.md),
[installation](../installation.md) and [limitations](../limitations.md#speech-analysis).

Downloads use up to 16 connections for a single large file. Progress displays
the downloader's received-byte information. Both platform release gates include
real speech-model loading and inference, offline use, Unicode paths, font
shaping and the existing aircraft/URL-intake checks. The validation record
separates read-speech quality measurements from package checks and geolocation.

The downloads are unsigned pre-release builds. Keep original recordings and
review names, numbers and translations against the audio before relying on them.
