# SoundGeo 0.3.0-alpha.1

First experimental binary release for Windows x64 and Linux x64. Includes the
desktop application and `soundgeo-cli`. Extract the archive and follow
`docs/installation.md`. FFmpeg is required and is installed separately.

## Included

- Aircraft Doppler and flight passage timing searches, including unknown start times.
- Free flight-reference downloads, offline caches, resumable searches and JSON reports.
- Location ambiguity checks using the current 1 km target, independent sound
  consensus and competing positions. Recording-clock ambiguity is reported separately.
- Offline `check-audio` to inspect a recording before preparing flight references.
- Optional local text recognition for visible place names and clocks, with a separate clue report.
- Improved checkpoint recovery and buffered reads for long searches.

## Validation and limits

The release workflow requires formatting, Clippy, all Rust tests, Python timing
tests, documentation tests and release builds on Windows and Ubuntu. It then
extracts each archive, verifies its hashes, runs the CLI against synthetic and
silent recordings, and checks that the desktop window opens in the runner VM.
The downloadable `validation-*.json` files record package checks and source revisions.

Reliable location recovery from varied internet recordings remains unfinished.
The historical 27-recording timing benchmark returned eight locations within
1 km, five ambiguous results and fourteen insufficient-evidence results. Those
eight successes cover only two sites. These are development results from their
recorded revisions, not an accuracy guarantee for this release.

Heathrow remains ambiguous. Its three unmatched sounds fail the existing physical
fit thresholds. The two public investigative clips checked most recently had
insufficient audio evidence; neither produced a location. Full results and
scope are in [limitations](https://github.com/Donovoi/soundgeo/blob/v0.3.0-alpha.1/docs/limitations.md)
and the [validation record](https://github.com/Donovoi/soundgeo/blob/v0.3.0-alpha.1/validation/README.md).

Downloads are unsigned. Linux binaries target Ubuntu 24.04 x64 or compatible
systems with glibc 2.39 or newer. No macOS or ARM binaries are included.
`SHA256SUMS.txt` verifies the release downloads. Keep complete cache folders and
original reports when upgrading; older reports without complete competitor
evidence cannot establish a newly accepted Doppler location by reassessment.
