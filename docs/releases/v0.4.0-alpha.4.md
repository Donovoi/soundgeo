# SoundGeo 0.4.0-alpha.4

Background work now has a persistent panel above the results. It shows the active
operation, elapsed time, time since the last worker update, and a visible cancel
button. Combined analysis lists video clues, speech and location search in order.
Each stage shows whether it is waiting, working, complete or needs attention.
Progress bars describe the current operation; they can restart for another file
or stage. Completion, cancellation and errors remain visible.

An optional speech failure now allows location analysis to continue, matching
the video-clue behavior. Cancellation still stops the remaining stages. A worker
that exits without a result reports an error instead of leaving a permanent
spinner. Speech results explain when a language choice is required and how to
continue. A completed analysis explicitly distinguishes candidate locations,
ambiguity and insufficient evidence.

File-path fields keep keyboard focus when their help text changes, so entering
a custom place-data path no longer stops partway through typing.

Automatic flight-date discovery retains verified dates when GitHub reaches its
1,000-release listing limit. The catalog and analysis report explicitly identify
incomplete date coverage. An explicit date range can check older days directly.
Other provider errors still fail visibly.

See the [desktop instructions](../../README.md#use-the-desktop-application).
Location acceptance rules and bundled model choices are unchanged.
