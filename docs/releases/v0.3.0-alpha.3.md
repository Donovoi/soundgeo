# SoundGeo 0.3.0-alpha.3

Download the Windows x64 EXE and run it. The app now accepts HTTP(S) media and
page URLs: find the available clips, choose one, and download it for local
analysis. The command line supports `fetch-media` and `analyze --url`.

The EXE includes current yt-dlp, gallery-dl, curl_cffi browser impersonation,
Deno, aria2, FFmpeg, FFprobe, English OCR and software graphics. The downloaders
are built with pinned dependencies; aria2 uses Windows TLS and DNS. Runtime
sources, build recipes, notices, hashes and version records accompany the release.

Large reference archives use resumable parallel transfers, adapting concurrency
to available bandwidth. Signed flight samples, airport replay and terrain also
download concurrently. Completed files are verified before cache reuse. Media
downloads preserve video and audio, keep provenance separately from analysis,
and support offline reuse of verified files.

This is an unsigned experimental release. Its geolocation target remains 1 km;
broad real-world accuracy has not been established. URL intake does not change
the matching model or turn insufficient sound evidence into a location result.
See [installation](../installation.md), [URL intake](../url-intake.md),
[limitations](../limitations.md) and the [validation record](../../validation/README.md).
