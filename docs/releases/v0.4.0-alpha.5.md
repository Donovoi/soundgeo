# SoundGeo 0.4.0-alpha.5

Recording requirements appear immediately. Selecting, dropping or downloading a
recording starts a local check with visible progress. The panel shows its duration,
sound counts and eligibility for each method: Doppler needs 20 seconds and two
separate pitch curves; passage timing needs eight minutes and six sound peaks,
plus a search area. Both support up to two hours. Continuity and aircraft identity
still require review. Passing these input checks does not verify a location.

Eligible analysis reuses its completed audio check after verifying the recording
hash and detector settings. Below-minimum recordings can still run checked speech
and video-clue options; their location stage skips flight downloads.

Automatic flight downloads remain enabled by default. The panel explains whether
data will download, reuse the cache, or remain offline. A visible action enables
online automatic downloads without starting a search. New desktop caches use the
user's writable cache folder; an existing launch-folder flight cache is reused.

See the [desktop instructions](../../README.md#use-the-desktop-application).
